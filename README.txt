PROJECT DESCRIPTION (EDIT TO MATCH YOUR WORK)
This project is Ayush Yadav's responsive personal portfolio website, built with HTML5 and CSS3. It introduces his MCA (Integrated) studies at Noida Institute of Engineering and Technology (NIET), Greater Noida, and includes Home, About Me, Skills, Projects, and Contact sections. CSS Grid and Flexbox are used to organize the content, and media queries help the layout adapt to smaller screens. The website uses navigation links, styled cards, and hover/focus states to make the page easier to use.
